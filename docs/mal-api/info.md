## Official

#### API

MyAnimeList has released a public API which allows you to send and retrieve data without using the MAL website. To use
the API, you must first provide information about your application and obtain a client ID. You can do this in the API
tab of your profile settings (MAL account required).

Our customer support team will not provide answers to technical questions about the API or how to use it. For inquiries,
bug reports, and other support, please use the[MAL API Club.](https://myanimelist.net/clubs.php?cid=13727)

Welcome to the MyAnimeList "Open Beta" API!
We're excited to have you join us in this public phase of our development efforts! Below, you'll find resources and
documentation to help you get started working with the MAL API. Please note, the API is still in active development and
while this current phase is somewhat feature-bare, there are numerous features and changes we want to see implemented in
the future.

General Information Below, you'll find resources and documentation to help you get started working with the MyAnimeList
API. Please note, the API is still in active development, and there are numerous features and changes planned for future
releases.

Notes:
You can request up to 5 IDs. We will occasionally review applications that use the API and their services. If your
application does not comply with Terms of Use of the API, we will terminate the application's access. Please make sure
the email address on your account is up-to-date before creating a Client ID. For questions, bug reports, and general
discussion about the API, please join us at the MAL API Club.
